    Concept development

    Drawing is still the fastest tool in the building.

    Every project starts on paper. Coloured concept sketches carry construction notes — lacing, stitching, sole build, panel colour — so that a drawing already contains the information a pattern cutter needs.

    It is cheap to change a line. It is expensive to change a cut piece of leather, and ruinous to change a production run.

    Technical toolkit

    Hand skills, backed by CAD.

    Digital development is used where it earns its place: precision, repeatability, grading and clean handover to a factory. The hand still decides whether the shoe is any good.
